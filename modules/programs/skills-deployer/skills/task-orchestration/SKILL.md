# Task Orchestration

The parent owns the requested outcome.

Handle atomic work directly. Delegate independent objectives concurrently when doing so creates useful separation of evidence or capability. Keep every handoff local and sufficient for its objective. Continue independent parent work while background work runs.

Before concluding, inspect, integrate, and verify returned evidence against the current source state and the user's outcome.

Return the completed parent outcome with integrated evidence, deviations, and unresolved risks.
