* About This Repository

My personal dotfiles, managed declaratively with [[https://github.com/yunfachi/denix][Denix]], [[https://github.com/nix-darwin/nix-darwin][nix-darwin]], and [[https://github.com/nix-community/home-manager][Home Manager]].
They are tailored to my own machines and accounts, not maintained as a reusable template.

Denix discovers =.nix= files under =hosts/=, =modules/=, and =rices/=.
Ownership rules and the change checklist live in =docs/denix-architecture.md=.

* Repository Layout

- =hosts/= contains machine facts and host-only bindings.
- =modules/= contains reusable program, service, shared-data, and toplevel integration modules.
- =rices/= contains desktop-experience policy selected through repository-owned interfaces.
- =docs/= contains stable cross-cutting policy and runbooks.
- =packages/= contains repository-owned package derivations.
