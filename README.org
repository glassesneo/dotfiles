* About

This repository manages my machines and user environment with the rewrite branch of [[https://github.com/yunfachi/denix][Denix]], [[https://github.com/nix-darwin/nix-darwin][nix-darwin]], and standalone [[https://github.com/feel-co/hjem][Hjem]]. It is a personal configuration, not a reusable template.

* Layout

- =abstractions/= contains auto-discovered Denix hosts and modules.
- =adapters/= connects Denix to unsupported module systems such as Hjem.
- =extensions/= extends Denix itself, such as host attributes.
- =tests/= contains sandboxed checks discovered as flake checks.
- =scripts/= contains procedures that modify user or system state.
- =docs/= contains durable cross-cutting contracts and runbooks. Start with [[file:docs/architecture.md][the architecture contract]].

* Commands

Enter the development shell before using the repository commands:

#+begin_src sh
nix develop
#+end_src

Format and validate the repository:

#+begin_src sh
just fmt
just eval
just check hjem
nix flake check
#+end_src

Commands take the form =just <layer> <operation> [host]=. The layers are =hjem=, =darwin=, and =all= (nix-darwin, then Hjem); the operations are =build= and =switch=. An omitted host means this machine:

#+begin_src sh
just hjem build
just all switch
just darwin switch seiran
#+end_src

=build= realizes a configuration without changing any state. =switch= applies it to this machine; applying another host requires an SSH destination through =--target=:

#+begin_src sh
just all switch seiran-vm1 --target seiran-vm1-raw
#+end_src

Hjem activation is not transactional; see [[file:docs/commands.md][the command contract]] for the failure boundary.
